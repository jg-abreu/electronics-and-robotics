# Electronics & Robotics

My personal space for learning and experimenting with electronics, robotics, and embedded systems.

This repository documents my hands-on experiments with **Arduino, ESP32, sensors, circuits, and microcontrollers**.

The goal is simple: explore ideas, understand how things work, build things, and keep a record of what I learn.

## Technologies & Tools

- **Microcontrollers:** Arduino Uno, ESP32
- **Programming:** C/C++
- **Electronics:** Sensors, LEDs, displays, motors, and electronic circuits
- **Simulation:** Wokwi, Tinkercad Circuits
- **Development:** Arduino IDE, Git, GitHub

## Repository Structure

| Directory | Description |
|---|---|
| `arduino/` | Experiments and projects using Arduino |
| `esp32/` | ESP32 experiments, connectivity, and IoT |
| `robotics/` | Robotics, motors, and mechanical projects |

## Project Documentation

Each experiment may include:

- Source code
- Components and connections
- Circuit diagrams or simulation files
- Photos of physical prototypes
- Notes on how to reproduce the experiment

Projects may be simulated, physically tested, or both.

## About

This is a personal learning repository, not a collection of production-ready projects.

Experiments may be incomplete, improved, rebuilt, or revisited as I learn.

**Learn. Experiment. Build. Repeat.**
